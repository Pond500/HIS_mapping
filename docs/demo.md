# คู่มือ demo สด (D3, D4)

ทุกขั้นใช้ไฟล์จากชุดพัฒนา (`testdata/dev/`) ที่ระบบ**ทำแบบนั้นจริง** ไม่ได้จัดฉากไว้
ห้ามใช้ไฟล์ชุดสอบ (`testdata/exam/`) ใน demo เพราะชุดนั้นเก็บไว้ใช้รายงานตัวเลข

## ก่อนวันจริง: ซ้อม 1 รอบเพื่อบันทึกคำตอบ AI

1. `.env`: `LLM_MODE=live` และ `AUTO_ACCEPT=on`
2. `docker compose up -d --build` แล้วเปิด `http://localhost:<APP_PORT>`
3. เดินตามขั้นตอนด้านล่างครบทุกขั้น ระบบจะบันทึกคำตอบของ AI ทุกครั้งไว้ใน `storage/llm_cache/` (เป็นชื่อ lab และค่าตัวอย่าง ไม่มีชื่อหรือเลขบัตร)
4. ล้างข้อมูลที่ได้จากการซ้อม (**ต้องทำ** ไม่อย่างนั้นวัน demo ระบบจะจำทุกอย่างแล้วผ่านเองหมด จะไม่มีหน้ารอตรวจให้โชว์):
   `docker compose exec app python scripts/reset_demo.py --yes`
   คำสั่งนี้ล้างเฉพาะข้อมูล ส่วนพจนานุกรมกลางและคำตอบ AI ที่บันทึกไว้ยังอยู่

## วันจริง

- `.env`: `LLM_MODE=fallback` และ `LLM_TIMEOUT_S=45` → `docker compose up -d` (ไม่ต้อง build ใหม่)
  ระบบจะเรียก AI จริงก่อน ถ้าเน็ตล่มหรือช้ากว่า 45 วินาที จะใช้คำตอบที่บันทึกไว้ตอนซ้อมทันที
  ถ้าไม่มีเน็ตเลยตั้งแต่ต้น ใช้ `LLM_MODE=replay`
- ถ้าเจอคำถามที่ไม่มีคำตอบบันทึกไว้ ระบบจะส่งรายการนั้นให้คนดู ไม่เดา (กฎเหล็กยังคงอยู่)
- **ห้ามรัน `docker compose up --build` ระหว่าง demo** เพราะอาจทำให้ Postgres restart
